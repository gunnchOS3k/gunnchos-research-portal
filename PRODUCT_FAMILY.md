# Product family

Five first-party physical products:

1. **Student 14.5** — sustained learning and work
2. **Handheld Hybrid** — mobile and docked compute
3. **DS-XL Coder** — dual-screen learn/build/test/deploy-local
4. **Edge I/O Rings** — embodied low-latency input with confidence gating
5. **First-party Dock** — continuity and desktop expansion

All run **gunnchOS**. Gaming must not erase education/work purpose.

Hardware source of truth: [`gunnchos-hardware-industrial-design`](https://github.com/gunnchOS3k/gunnchos-hardware-industrial-design)
