# Educator / Student path — gunnchOS Ecosystem v1.0.0-rc.1

## What WAIKE is

WAIKE is the learning platform + curriculum operations layer: **18 tracks**, lesson/activity surfaces, assessment lifecycle contracts, and optional gunnchAI tutoring — designed to run with Device OS / Capsule on a demo Pixel.

## Student journey (demo)

1. Open gunnchOS Capsule / Home
2. Enter WAIKE with seeded demo identity (no personal accounts)
3. Open a track → lesson
4. Optional: gunnchAI tutor (truthful availability)
5. Optional: launch an experience (game) as applied practice
