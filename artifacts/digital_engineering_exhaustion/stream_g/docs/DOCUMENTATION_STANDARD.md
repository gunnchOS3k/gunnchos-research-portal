# Documentation standard (Section 20)

Every public/recruiter/research-facing repo must expose:

1. README (entry)
2. One-paragraph explanation
3. Architecture diagram (Mermaid or linked UML)
4. Quick start
5. Demo path
6. Glossary (local or link to portal GLOSSARY.md)
7. Repo map
8. Requirements pointer
9. Test commands
10. Known limitations
11. Evidence status
12. CONTRIBUTING
13. SECURITY
14. LICENSE
15. Support/contact boundary

Stream G delivers `docs/stream_g/NEWCOMER_PACK.md` in each target repo (or a portal mirror when a repo PR is deferred) so the checklist is machine-auditable without stomping Stream A journey files.
