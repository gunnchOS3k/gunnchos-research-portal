# Co-supervision after Ari — sequencing rule

**Rule:** do **not** send simultaneous generic faculty outreach.  
Sequence:

```text
ARI DISCUSSION
  → identify scientific depth gap
  → choose co-supervision angle
  → targeted follow-up (with Ari’s advice when available)
```

No names below are proposed as committed co-supervisors. Names, if used later, must be re-verified on official UOulu pages at contact time.

## Scientific need → expertise angle

| If Ari discussion surfaces this gap… | Seek co-supervision depth in… | Why it helps V3 |
|---|---|---|
| Learning/control justification under radio dynamics | RRM / distributed AI / constrained learning | Paper II: when learning beats rules; information-equivalent baselines; uncertainty |
| Device–system disruption experiments, IoT/NTN edge cases | Dependable IoT / TN–NTN / device-system experimentation | Paper III: fallback modes, energy/privacy on constrained devices |
| Link/system fidelity of beam, blockage, PHY abstractions | MIMO/OFDM / PHY / link–system optimization | Bound ReadyGary/SpectrumX abstractions; avoid over-claiming PHY novelty |

## What not to do

- Parallel mass email to theme leaders.
- Present co-supervisors before principal-supervisor conversation.
- Treat optional partners (Nokia, NVIDIA tooling) as academic co-supervisors.
- Expand to a fourth paper to “use” a co-supervisor.

“Principal scientific risk is _____; co-supervision angle is _____.”  
Then update this memo with dated, source-verified contacts **only after** that decision.
