# Friend Cold-User Script — V3

State goals, not button instructions.

## PartyLink — Anime
1. Get into a shared-screen Party Mode session with friends on phones.  
2. Join as player and as spectator.  
3. Play a short match; notice Arena View on the big screen.  
4. Drop and reconnect.  
5. Rematch or rotate seats.

## PartyLink — Pedestrian
1. Start a Party Race host.  
2. Join from phone controllers (2–8).  
3. Complete a race; check finish order feels fair.  
4. Use Race Director view if available.  
5. Reconnect mid-race if possible.

## Universal shell / MLV
1. On your current host OS, open Home → Campus → Gallery.  
2. Note anything that feels host-specific or broken.

## Archive
1. Search ArchiveDex for a taxon / synonym if exposed.  
2. Page through large results.  
3. Open Sources & Evidence; say whether claims feel trustworthy.
