# Privacy, Identity, Security, and Sharing Doctrine

## Identity principle
Identity should travel farther than private data.

## Home principle
A user's Home is private by default.

Friend access is not blanket access.

## Sharing levels
At minimum distinguish:
- private;
- shared with specific people;
- class/group;
- institution;
- public/Gallery.

## Shared-device principle
Shared/lab devices must preserve:
- account separation;
- private files;
- sessions;
- permissions;
- recovery.

## AI principle
AI must respect the same permission boundaries as the user/system role invoking it.

## Security principle
Security should be built into:
- identity;
- update;
- recovery;
- secrets;
- network behavior;
- plugin/app permissions;
- telemetry.

## Physical/spatial input
Edge I/O and future wearables may reveal sensitive interaction data.

Collection should be:
- purposeful;
- minimized;
- visible;
- bounded;
- reviewable.

## Public sharing principle
Publishing is a state change.

The UI should make that transition understandable.
