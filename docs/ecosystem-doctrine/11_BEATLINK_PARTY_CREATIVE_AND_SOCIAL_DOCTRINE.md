# BeatLink Party Creative and Social Doctrine

## Role

BeatLink Party is a shared music/social party experience.

## Core philosophy
The room should feel alive.

The user should experience:
- stage energy;
- audience/participant presence;
- synchronized social action;
- clear room creation/join flow;
- useful shared-screen state.

## Multi-client doctrine
Multiple devices should join one coherent session without confusion over:
- room;
- role;
- identity;
- current activity;
- shared state.

## Music/rightsholder doctrine
The product must have a rights-safe release mode.

Commercial catalogs, Spotify-style gameplay, or protected music cannot be treated as cleared merely because integration is technically possible.

## Current state
Multi-client/Stage Energy systems exist.

## Future state
A polished social music game that can expand into deeper licensed content when rights allow.
