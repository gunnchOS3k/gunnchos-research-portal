# 3k MLV World and UX Doctrine

## Role

3k MLV is the portable world shell.

It should feel less like an application launcher and more like a place.

## Canonical geography

### Home
Private/personal.

Must support:
- private workbench;
- media;
- personal games;
- private drafts;
- selective friend access;
- logout/rest metaphor;
- personal device continuity.

### Campus
Learning/research/collaboration.

Must support:
- WAIKE;
- courses;
- labs;
- groups;
- instructors;
- research campuses;
- institutional tools;
- shared academic spaces.

### Gallery
Public/shared.

Must support:
- approved publishing;
- portfolios;
- creations;
- public projects;
- shared research;
- community discovery.

## UX law

A user should always understand:
- where they are;
- whether the space is private/shared/public;
- who can see what;
- what action takes them somewhere else;
- whether an action changes public visibility.

## Current state
- three-place architecture exists;
- universal-shell direction exists;
- 7GC world/campus work exists;
- Cloudflare deployment is being prepared.

## Future state
- persistent identity;
- seamless device switching;
- richer public/social world;
- integrated Campus and Gallery;
- first-party and validated third-party hosts;
- public `gunnchos.com` gateway.

## Anti-pattern
Do not make 3k MLV a decorative menu on top of unrelated apps.
