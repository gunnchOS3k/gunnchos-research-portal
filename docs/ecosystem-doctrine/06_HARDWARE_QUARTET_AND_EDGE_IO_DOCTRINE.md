# Hardware Quartet and Edge I/O Doctrine

## Role

The Hardware Quartet is the first-party physical expression of the ecosystem.

## Student 14.5
**Job:** desk/shared-lab/student productivity.

Should prioritize:
- readable learning workspace;
- keyboard/desk work;
- shared lab use;
- affordability;
- maintainability;
- classroom/college workflows.

## Handheld Hybrid
**Job:** portable + docked continuity.

Should support:
- games;
- learning;
- media;
- communication;
- portable creation;
- docked expansion;
- PartyLink participation.

## DS-XL Coder
**Job:** dual-screen creation/research.

Should prioritize:
- code + output;
- documentation + work;
- simulation + control;
- research instrumentation;
- technical creation.

## Edge I/O Rings
**Job:** embodied/spatial input.

Long-term concept:
- detect the device/surface;
- infer intended interaction;
- enable clicks/keystrokes/edits/spatial control;
- reduce dependence on traditional keyboard/mouse when appropriate.

## Principles
- hardware follows user roles, not arbitrary SKU multiplication;
- form factor should change how the ecosystem is used;
- continuity beats novelty;
- safety, ergonomics, RF, battery, certification, manufacturing, and warranty require real-world evidence.

## Current state
Digital engineering/design profiles and supporting research exist.

## Future state
Validated physical products that express the same world in different physical contexts.

## Boundary
Digital design ≠ EVT.
Prototype ≠ certified product.
Rendering ≠ manufacturability.
