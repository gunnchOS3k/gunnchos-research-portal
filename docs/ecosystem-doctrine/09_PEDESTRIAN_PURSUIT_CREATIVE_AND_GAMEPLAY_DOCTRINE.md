# Pedestrian Pursuit Creative and Gameplay Doctrine

## Role

Pedestrian Pursuit should feel like a complete arcade/social racing game, not a movement prototype.

## Core philosophy
The world/course itself is part of the game identity.

Courses should differ through:
- topology;
- macro terrain;
- silhouette;
- hazards;
- signature mechanic;
- boost moments;
- visual identity.

## Power-up doctrine
Items must be readable:
- at speed;
- from distance;
- under multiplayer pressure.

Effects should communicate:
- pickup;
- ownership;
- activation;
- consequence.

## Social doctrine
Party Race should make multiple personal controllers feel coherent around a shared race.

## Current state
V4 course identity and power-up readability work exists on PR #39.

## Future state
A fast, readable, replayable social racing experience that can function across personal devices and shared displays.
