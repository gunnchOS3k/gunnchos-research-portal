# Canonical Glossary and Naming

## gunnchOS
First-party OS/service layer and broader ecosystem brand.

## 3k MLV
Portable world shell that presents Home, Campus, and Gallery across validated hosts.

## Home
Private/personal space.

## Campus
Learning/research/collaboration space.

## Gallery
Public/shared creation/discovery space.

## WAIKE
Native learning platform and curriculum environment.

## gunnchAI
AI/intelligence layer for learners, instructors, creators, system help, and future operations.

## Hardware Quartet
- Student 14.5
- Handheld Hybrid
- DS-XL Coder
- Edge I/O Rings

## Host Capability Adapter
Compatibility layer connecting 3k MLV/world capabilities to the underlying OS/device.

## PartyLink
Shared-session architecture in which players use personal devices while a shared authoritative experience is displayed.

## Arena View
Shared display presentation for PartyLink game sessions.

## 7GC
Global validation/research network spanning digital twins, networks, devices, workloads, AI, and future field nodes.

## Exact-head
Evidence/artifact built from the exact commit being claimed.

## Human gate
Acceptance that requires human judgment.

## Physical gate
Acceptance requiring a real device, physical artifact, lab, field environment, or external hardware evidence.

## Claim boundary
Explicit statement of what current evidence does and does not prove.
