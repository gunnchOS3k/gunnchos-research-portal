# Archive of Life Creative and Knowledge Doctrine

## Role

Archive of Life combines:
- exploration;
- collection;
- museum/archive interaction;
- scientific/knowledge discovery;
- creature/species information;
- world navigation.

The intended experience should feel like a real discovery game, not a database browser or generic arena prototype.

## Core experience
The user should be able to:
- explore;
- encounter;
- collect/discover;
- inspect sources;
- understand provenance;
- move between game world and knowledge archive.

## Knowledge doctrine
Every scientific claim should preserve source traceability.

The system must distinguish:
- engineering capability;
- source snapshot availability;
- normalized data;
- scientific review;
- completeness.

## Current state
Living Archive work and ingestion engineering exist.

## Future state
A rich world-scale learning/discovery game backed by traceable scientific knowledge.

## Boundary
The ingestion engine is not proof that every species or source is complete.
Scientific completeness must remain an explicit external/human gate.
