# gunnchAI Intelligence Doctrine

## Role

gunnchAI is the intelligence layer of the ecosystem.

It should be contextual, useful, inspectable, and subordinate to user/instructor authority.

## Student-side vision
gunnchAI can:
- explain;
- answer questions;
- demonstrate;
- coach;
- help debug;
- help plan;
- help complete learning tasks within the platform's rules;
- connect concepts to real ecosystem artifacts.

## Instructor-side vision
gunnchAI can support:
- lesson planning;
- assignment design;
- feedback;
- rubric interpretation;
- grading assistance;
- content adaptation;
- learner support.

## Ecosystem-side vision
It may eventually support:
- system help;
- device setup;
- network/research operations;
- creator workflows;
- documentation;
- troubleshooting.

## Principles
1. AI should reduce friction, not obscure control.
2. User privacy and role boundaries matter.
3. Instructor/system source-of-truth must remain distinct from generated output.
4. Evaluation must separate automated metrics from human judgment.
5. Live-provider status must be explicit.
6. Model/provider changes must not silently change claims.
7. AI should teach the user how the system works when appropriate.

## Current state
Digital AI workflows and WAIKE integration exist; live provider qualification and human evaluation remain separate gates.

## Future state
A deeply contextual assistant that understands the user's world, permissions, learning context, devices, and projects without becoming an uncontrolled authority.
