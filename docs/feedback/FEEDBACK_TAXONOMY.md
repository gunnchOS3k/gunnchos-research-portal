# Public feedback taxonomy (V1)

Central labels for portal issues. Create on GitHub when missing (owner/ops).

## Kind / topic

`feedback`, `bug`, `feature`, `docs`, `accessibility`, `research`, `hardware`, `game`, `waike`, `gunnchai`, `device-os`, `curriculum`

## Workflow

`needs-repro`, `needs-design`, `needs-triage`, `accepted`, `declined`, `planned`, `in-progress`, `released`

## Priority

`P0-security`, `P1-blocker`, `P2-important`, `P3-normal`, `P4-idea`

Also keep existing lane labels (`lane:*`, `feedback:*`, `priority:p0`…`p3`, `roadmap:candidate`, `release:*`) during transition.

## Security rule

Security content must **not** remain public merely because a label exists. Convert public vuln reports to private advisories immediately.
