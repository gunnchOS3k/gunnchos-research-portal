# WAIKE Learner / Instructor Alpha Protocol

**Evidence class:** `HUMAN_VALIDATION_PENDING`  
**Adult learners + instructors only** for this alpha wave.

## Tasks
1. Learner: complete one lesson path end-to-end.
2. Instructor: review progress signal / feedback loop.
3. Cross-check curriculum track IDs against `waike-research-ops` maps.

## Metrics
- Completion, comprehension check (instructor judgment), defect log, integrity incidents.

## Stop conditions
- K-12 without approved consent path.
- Rights/curriculum mislabeling presented as accredited courseware.

## Result schema
Same shape as staff alpha with `"cohort": "learner_instructor_alpha"`.
