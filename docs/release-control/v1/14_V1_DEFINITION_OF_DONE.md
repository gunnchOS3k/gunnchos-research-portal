# v1.0.0 Definition of Done

Final v1 is done when required conditions pass or are explicitly owner-waived with documentation.

## Release control
- fresh accepted-main manifest
- no unintentionally open selected PR
- no stale release pin used as current authority
- unknown-gate count zero
- every non-pass gate classified
- explicit final authorization

## Core product
- 3k MLV Home/Campus/Gallery works
- WAIKE core learner journey works
- gunnchAI supported flow works within provider boundary
- Device OS/Capsule works
- each included game has a real playable flow
- research portal exposes selected v1 systems

## Public delivery
- required hostnames live
- TLS valid
- mobile/desktop smoke
- deep links work
- deployment identity maps to accepted SHA

## Game closure
- Anime physical/human gates recorded if #118 is included
- Pedestrian owner review recorded if #39 is included
- Archive science claims stay bounded
- BeatLink content is rights-safe

## Security / feedback
- no known committed secrets
- private security reporting where required
- feedback front door
- current update/recovery/security evidence
- privacy claims match implementation

## Out-of-scope gates
A gate may remain false if it is explicitly outside v1 and clearly documented:
- EVT
- carrier certification
- manufacturing
- K-12 institutional rollout
- scientific completeness
- commercial music rights

## Release package
- artifacts
- hashes
- release notes
- known limitations
- provenance/rights
- host matrix
- deployment manifest
- final candidate reviewed
