# v1.0.0 Release Charter and Scope Authority

## Release identity

**gunnchOS Ecosystem v1.0.0 — Software + Digital Platform Release**

v1.0.0 is the first coherent public release of the software ecosystem, digital hardware engineering, games, learning platform, AI layer, Device OS, 3k MLV world shell, and research systems.

It is **not** a declaration that every physical, regulatory, scientific, institutional, licensing, manufacturing, or carrier milestone is complete.

## Claim boundary

Allowed:

> gunnchOS Ecosystem v1.0.0 is a working software and digital-engineering release with playable experiences, learning/AI systems, Device OS integration, research tooling, and public web surfaces.

Not allowed without separate evidence:

> production-ready consumer hardware, carrier-certified 6G product, fully institutionally certified LMS, scientifically complete world-life database, or commercially licensed music platform.
