# Role Fit Overview

This portfolio is organized around three **role-aligned proof paths** for defensive security, access risk, and hardware verification — plus the existing 6G / digital-equity research spine.

## Technical lanes

| Lane | Primary repo | Target role families |
|------|--------------|----------------------|
| **Agentic SecOps** | [gunnchAI3k](https://github.com/gunnchOS3k/gunnchAI3k) | Google / Mandiant — Associate Security Analyst, Agentic Security Operations |
| **Access Risk Intelligence** | [gunnchos-device-os](https://github.com/gunnchOS3k/gunnchos-device-os) | Google PRISM / Access Risk Security Engineer |
| **Console RTL Verification** | [eg3573-ece-6443-sram-bist-project](https://github.com/gunnchOS3k/eg3573-ece-6443-sram-bist-project) | Google Digital Design Verification / RTL / UVM |

## Each lane includes

- Working or **mock-safe** demos (offline, synthetic data)
- Evidence-tracked documentation ([CLAIMS_TO_EVIDENCE](https://github.com/gunnchOS3k/gunnchos-research-portal/blob/main/CLAIMS_TO_EVIDENCE.md) pattern)
- Reproducibility notes
- Explicit limitations — **not** production-ready claims
- Next steps and CI smoke validation
