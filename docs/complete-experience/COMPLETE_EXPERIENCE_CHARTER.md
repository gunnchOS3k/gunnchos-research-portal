# Complete Experience Charter (CX0)

## Mission

Establish a truthful, machine-readable Complete Experience control plane for gunnchOS3k without destabilizing the Device Lab release train.

## CX0 scope (this prompt)

1. Organization-wide read-only inventory → `CAPABILITY_REGISTRY.json`  
2. Control-plane documents under `docs/complete-experience/`  
3. Versioned platform contracts  
4. Optional additive foundation DRAFT PRs in Device OS / WAIKE / gunnchAI when gaps confirmed  
5. Provider qualification matrix (candidates, not standardization)  
6. Persona acceptance definitions  
7. Gap backlog + implementation waves  

## Out of scope for CX0

- Merges of any kind  
- Modifications to Device OS #134 or Portal #14 release-control sequences  
- Changes to Device Lab accepted-main pins  
- Claiming FULL_COMPLETE_EXPERIENCE_COMPLETE  
- Physical/human certification campaigns  

## Success criteria

Organization has one portfolio-level view of requirements, coverage, gaps, ownership, and next wave — DRAFT PRs only.
