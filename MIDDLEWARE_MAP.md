# Middleware map

Core platform services expected on gunnchOS:

- Identity and permissions
- Ring / Spatial input services (confidence + safe rejection)
- Display and dock manager
- Continuity / user-owned sync fabric
- Local AI runtime host
- Connectivity orchestrator (multi-bearer, degrade, offline)
- Package, update, rollback, recovery
- Fleet / device management and revoke
- Accessibility services
- Telemetry with privacy controls

Fixtures and mocks are not final runtime. Device Lab may simulate peripherals for digital proof; physical correlation remains pending.
