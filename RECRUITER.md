# Recruiter path — gunnchOS Ecosystem v1.0.0-rc.1

**Read time:** 2–3 minutes

## One paragraph

gunnchOS is Edmund Gunn Jr.’s integrated computing ecosystem: a Device OS and Android Capsule shell, WAIKE (18-track learning platform + curriculum ops), gunnchAI (local-first edge intelligence), a Device Quartet hardware digital-engineering line, 6G/AI-RAN/NTN/digital-twin research systems, and four interactive experiences that stress realtime input, physics, scientific evidence, and multi-device networking — frozen at accepted `main` as **v1.0.0-rc.1**.
